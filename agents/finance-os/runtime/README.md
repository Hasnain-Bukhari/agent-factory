# Finance OS local core

This runtime contains gate-passed Phase 2 encrypted persistence, Phase 3 portable interchange/MCP, and the Phase 4 synthetic ChatGPT interaction harness. It remains **synthetic-data only until an explicit real-data pilot approval**. The MCP service is loopback-only; no external ChatGPT connection, public endpoint, Telegram adapter, or dashboard is included. It supports Apple-silicon macOS with Node.js 22. Encryption uses Node's maintained OpenSSL-backed `crypto`, persistence uses Node filesystem primitives, and the production key-provider adapter uses macOS Keychain through `/usr/bin/security`. Direct dependencies are lockfile-pinned Ajv 8.20.0, `@modelcontextprotocol/sdk` 1.32.2, and Zod 4.6.7.

Run `npm test` for the synthetic gate and `node bin/finance-os.mjs doctor` for a non-sensitive host check. `bin/finance-os-mcp.mjs` starts the authenticated Streamable HTTP endpoint only on `127.0.0.1`; it requires an owner-only credential file and never exposes raw file, store, or key tools. Lifecycle, recovery, and Phase 3 boundaries are described in [`../references/operations.md`](../references/operations.md) and [`../references/runtime-phase3.md`](../references/runtime-phase3.md). Do not initialize a real store, connect ChatGPT, or supply personal records until the applicable later gate and explicit approval.
